# AI 象棋

一款运行在手机浏览器上的 AI 中国象棋，支持将网页「添加到主屏幕」，像 App 一样离线使用（PWA）。

## 功能

- **人机对战**：4 档难度（入门 / 初级 / 中级 / 高级），可选执红（先手）或执黑
- **触屏友好**：竖屏布局，点选棋子后显示可走位（绿点）与可吃子（红圈）
- **悔棋**：一次撤回你和 AI 的各一步
- **提示**：用当前最高档 AI 给出一手建议并高亮 4 秒
- **教练提醒**：被将军、大子受攻时实时提示
- **自动续局**：关闭页面后重新打开，对局自动恢复
- **离线可用**：安装到主屏幕后无需网络

## 运行

纯静态站点，任意静态托管即可（需 HTTPS 才能启用离线安装）。用现代浏览器打开 `index.html` 所在目录即可游玩。

## 技术

原生 HTML/CSS/JS，无构建、无依赖。棋盘为 SVG + DOM 渲染；走子规则为独立引擎（`js/rules.js`）；AI 为 negamax + α-β 剪枝（`js/ai.js`），运行在 Web Worker 中不阻塞界面；离线缓存由 Service Worker 提供。
